# SaaS / E-Commerce Cohort Retention & CLTV Analysis

## Project Overview

This project analyzes customer retention and Customer Lifetime Value (CLTV) using cohort analysis. The objective is to understand customer retention patterns, identify customer drop-off points, and provide actionable business recommendations.

## Dataset

Online Retail II (UCI) dataset from Kaggle.

## Tools Used

- Power BI
- Excel
- Python
- Pandas
- SQL

## Key Metrics

- Average Customer Lifetime Value (CLTV): 359.65
- Average Order Value (AOV): 251.89
- Purchase Frequency: 9.02

## Key Visualizations

- Customer Cohort Retention Matrix
- Customer Retention Trend
- CLTV KPI
- Average Order Value KPI
- Purchase Frequency KPI

## Key Insights

- Customer retention drops significantly after the first month.
- Retention gradually declines as the cohort age increases.
- Early customer engagement is important for improving long-term retention.
- The analysis helps identify customer retention and drop-off patterns.

## Business Recommendations

- Focus on customer engagement during the first month.
- Use personalized offers and reminders to encourage repeat purchases.
- Implement re-engagement campaigns for inactive customers.
- Study high-retention cohorts and apply their successful strategies to other customer groups.

## Conclusion

The cohort retention and CLTV analysis provides insights into customer behavior and helps businesses develop strategies to improve customer retention and customer lifetime value.
